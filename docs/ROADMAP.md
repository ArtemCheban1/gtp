# Roadmap

Кожна задача описана так, щоб її можна було віддати окремій сесії Claude: що зробити, які файли, як перевірити.
Позначки моделі: **S** — підійде Sonnet (чітка, локальна задача), **O** — краще Opus (архітектура, багато файлів, складна геометрія/таймінг).

Перед завершенням будь-якої задачі: `npm run typecheck`, `npm run validate-data`, і перевірити кадр через
`npx remotion still remotion/index.ts GuessThePlace out/check.png --frame=<N>` (або подивитись у порталі).

## Наступне

### 1. Обрізка фото (crop/focus) — S ✅ зроблено
Зараз фото масштабується `object-fit: cover` по центру. Додати в `PhotoSlot` поле `focus: {x: number, y: number}` (0..1)
і використати `objectPosition` у `remotion/components/Photo.tsx`. У `portal/components/PhotoSlots.tsx` клік по мініатюрі ставить точку фокусу.

### 2. Обкладинка (thumbnail) — S ✅ зроблено
Додати друге `Composition` у `remotion/Root.tsx` (`Cover`, 1080×1920, 1 кадр): фото 1, великий напис "WHERE IS THIS?" і "3 guesses".
У сервері endpoint `/api/cover`, який рендерить через `renderStill`. Кнопка "Render cover" у `RenderPanel`.

### 3. Пакетний режим — S
Сторінка або секція порталу "Queue": вибрати кілька збережених проєктів і зрендерити по черзі (сервер має обробляти задачі послідовно — додати просту чергу в `server/index.ts`).

### 4. Клік по карті для вибору місця — S ✅ зроблено
У `PlacePicker` міні-карта (SVG, `d3-geo` + `COUNTRIES` із `shared/geo/world.ts`): клік ставить lat/lon. Корисно для місць без назви.

### 5. Підпис до посту й хештеги — S ✅ зроблено
Генерувати текст опису (англійською) з назвою місця, прихованою за спойлером ("Answer in the video 👀"), і хештеги (#geography #geoguessr #travel #<country>). Кнопка "Copy caption" у порталі.

### 6. Стилі/теми відео — S ✅ зроблено
Винести кольори в кілька тем (`remotion/theme.ts`), додати `theme` у `VideoProps` і селект у `SettingsPanel`.

### 7. Озвучка відповіді — O
Опціонально: голос "It's Oceania!" на кожному reveal. Варіанти: заздалегідь записані файли для 4 зон + 16 регіонів, або TTS-сервіс. Потрібно продумати синхронізацію з `T.reveal` у `shared/timeline.ts`.

### 8. Більше рівнів деталізації / інші режими гри — O
Наприклад, раунд 3 як 4 країни замість міст, або режим "5 фото — 5 раундів". Зачіпає `shared/rounds.ts`, `shared/timeline.ts`, `RoundSpec`, `MapView` — краще робити на сильнішій моделі.

### 9. Розширення списку міст — S
Додати по 5–10 відомих місць у регіони, де їх мало (`oc-nz`, `oc-west`, `af-north`), у `shared/geo/cities.ts`. Обов'язково `npm run validate-data` (перевіряє, що координати потрапляють у заявлену країну).

### 10. Автопублікація — O
Публікація в Facebook/Instagram через Graph API (потрібен бізнес-акаунт і токен). Окремий модуль сервера; токени — тільки в `.env`, ніколи в git.

## Відомі обмеження
- Дуже маленькі острови (наприклад, Бора-Бора) відсутні на карті 50m — для них треба вручну вибрати регіон у порталі.
- Якщо 4 міста раунду 3 дуже близько одне до одного, підписи можуть розʼїхатися далеко від точок — тоді краще замінити варіант.

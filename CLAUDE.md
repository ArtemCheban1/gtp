# Guess the Place — reel studio

Local tool that turns **3 photos + 1 place** into a 9:16 MP4 "Guess the Place" quiz reel
(GeoGuessr-style, 3 rounds: part of the world → region → exact place). Video text is English.

## Run
- `npm install` then `npm run dev` → portal on http://localhost:5173, API on :3001.
- `npm run studio` → Remotion Studio (frame-by-frame debugging of the video).
- `npm run typecheck` and `npm run validate-data` must pass before committing.
- If the render can't download Chrome (offline / sandbox), set `BROWSER_EXECUTABLE=/path/to/chrome-headless-shell`.

## Layout
- `shared/` — pure logic used by both the video and the portal. No React here.
  - `types.ts` — `VideoProps` is the single source of truth (Remotion inputProps = saved project JSON).
  - `timeline.ts` — all durations in frames (`T`, `roundStart`, `totalFrames`).
  - `rounds.ts` — `buildPlan(props)` turns props into 3 `RoundSpec`s (options, correct answer, map view).
  - `geo/regions.ts` — the 4 zones × 4 subregions, country lists, overseas overrides, meridian splits.
  - `geo/world.ts` — Natural Earth 50m countries (world-atlas), land grouped per subregion, `resolvePoint()`.
  - `geo/cities.ts` — curated city list (answer search + round-3 decoys).
  - `geo/camera.ts` — rotated-Mercator camera, fit-to-bbox, smooth fly between views.
- `remotion/` — the video. `GuessThePlace.tsx` = Intro → 3× `Round` → `Outro`. `theme.ts` has colours + layout.
- `portal/` — Vite + React UI with `@remotion/player` live preview.
- `server/index.ts` — Express: uploads, Nominatim geocoding proxy, render jobs (`@remotion/renderer`), projects.
- `public/` — sfx (generated by `npm run make-sfx`) and the bundled Montserrat font (OFL).
- `data/` (uploads, projects) and `out/` (MP4s) are git-ignored.

## Conventions
- Everything visible in the video must be deterministic for a given `VideoProps` (use `mulberry32(seed)`, never `Math.random()` in `remotion/` or `shared/`).
- Keep important content above y=1600 and away from the right ~120px — Reels/TikTok UI covers those areas.
- Country names in `regions.ts` must match `world-atlas/countries-50m.json` exactly; run `npm run validate-data`.
- Uploaded files are stored as `/uploads/...` relative URLs; the server makes them absolute only for rendering.
- To check a visual change without the portal: `npx remotion still remotion/index.ts GuessThePlace out/f.png --frame=140`.

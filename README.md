# Guess the Place — студія рілзів

Локальний портал: завантажуєш 3 фото, вибираєш правильне місце, і отримуєш готове відео 9:16 (MP4) для Reels / TikTok / Shorts.

**Сценарій відео (~29 с при 5 с на роздуми):**

1. Інтро "Guess the Place".
2. **Раунд 1.** Фото 1 + карта світу з 4 частинами (A — Америки, B — Європа й Азія, C — Африка, D — Океанія). Таймер 5 с з тіканням, потім показ правильної відповіді.
3. **Раунд 2.** Фото 2. Камера наближається до правильної частини світу, де є 4 регіони на вибір.
4. **Раунд 3.** Фото 3. Ще ближче: 4 міста на карті (правильне + 3 автоматично підібрані сусідні).
5. Фінал: назва місця, усі 3 фото, ланцюжок відповідей і заклик написати в коментарях, скільки вгадав.

## Запуск

Потрібен [Node.js](https://nodejs.org) 20 або новіший.

```bash
npm install
npm run dev
```

Відкрий http://localhost:5173.

Під час першого рендеру Remotion сам завантажить headless Chrome (~100 МБ, один раз). Готові відео з'являються в папці `out/`, а також у порталі (кнопка "Download video").

## Як користуватись

1. **The answer.** Почни вводити місто: список популярних міст підказує одразу. Для будь-якого іншого місця (пам'ятка, село) натисни "Search online" (пошук через OpenStreetMap). Під полем видно ланцюжок, наприклад `Oceania → Eastern Australia → Sydney`. Якщо регіон визначився неправильно, вибери його вручну.
2. **Photos.** Перетягни 3 фото, від найважчого до найлегшого. Підпис-підказку можна залишити порожнім.
3. **Round 3 options.** 3 неправильні варіанти підбираються автоматично. Кожен можна замінити, а кнопка "Shuffle options" перемішує їх.
4. **Timing, sound & text.** Тут налаштовуються час на роздуми (3–10 с), гучність тікання, твоя музика та тексти.
5. **Render MP4.**

"Save" зберігає проєкт у `data/projects/`, а "Open project…" відкриває збережений.

## Карти й звуки

- **Карти:** [Natural Earth](https://www.naturalearthdata.com/) (public domain) через пакет `world-atlas`. Малюються як вектор, тому ніяких API-ключів і ліцензійних обмежень.
- **Звуки** (тікання, дзвіночок, "whoosh") синтезовані скриптом `npm run make-sfx`, тож авторських прав на них немає.
- **Музика твоя.** Бери треки з бібліотек без авторських обмежень (YouTube Audio Library, Pixabay Music), а для Instagram і Facebook краще додавати музику з їхньої бібліотеки вже під час публікації.
- **Шрифт** Montserrat, ліцензія SIL OFL, лежить у `public/fonts`.
